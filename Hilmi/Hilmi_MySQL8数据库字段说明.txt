================================================================================
希尔米 Hilmi 项目 · MySQL 8.0 数据库说明（全中文）
================================================================================
数据库名称：hilmi
字符集：utf8mb4（支持中文和表情）
建表脚本：同目录「Hilmi_MySQL8建表脚本.sql」
数据表数量：14 张
================================================================================


【如何在 Navicat 里导入】
第一步：打开 Navicat，连接你的 MySQL 8.0。
第二步：菜单选「文件」→「运行 SQL 文件」。
第三步：选择桌面上的「Hilmi_MySQL8建表脚本.sql」。
第四步：点击「开始」，执行成功后左侧会出现 hilmi 数据库和 14 张表。

【媒体字段 media 怎么填 — 必看】
media 是一个 JSON 数组，里面每个元素是一张图或一个视频：

（1）一张图片：
{
  "type": "image",
  "storage_path": "moments/posts/用户id/文件名.jpg",
  "sort_order": 0
}
· type：固定写 image（图片）
· storage_path：图片存在服务器或云存储上的路径
· sort_order：第几张图，从 0 开始

（2）一个视频：
{
  "type": "video",
  "storage_path": "moments/posts/用户id/视频.mp4",
  "poster_path": "moments/posts/用户id/封面.jpg",
  "sort_order": 0
}
· type：固定写 video（视频）
· storage_path：视频文件路径
· poster_path：视频封面图路径（列表先显示封面）
· sort_order：一般为 0

（3）完整示例 — 一条帖子只有一个视频：
[
  {
    "type": "video",
    "storage_path": "moments/1.mp4",
    "poster_path": "moments/1/poster.jpg",
    "sort_order": 0
  }
]

（4）完整示例 — 一条帖子有两张图：
[
  {"type":"image","storage_path":"moments/posts/5/a.jpg","sort_order":0},
  {"type":"image","storage_path":"moments/posts/5/b.jpg","sort_order":1}
]

表与表之间怎么关联（中文说明）
================================================================================

用户表 是中心：
  · 直播间表的主播 → 用户表
  · 帖子表的作者 → 用户表
  · 评论、点赞、弹幕、私信、聊天室消息的发送者 → 用户表
  · 关注表、拉黑表的两端 → 用户表

直播间表 ← 直播弹幕表（一个房间很多条弹幕）
帖子表 ← 评论表、点赞表（一条帖子很多评论和点赞）
会话表 ← 私信消息表（一个会话很多条消息）
聊天室表 ← 成员表、公屏表
